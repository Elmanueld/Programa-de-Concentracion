# Programa-de-Concentracion

## Solución C#

Abre `src/CapaDatos/CapaDatos.sln` para trabajar con las capas de presentación, negocio, datos y entidades. La base de datos y sus scripts de instalación están en `database/`.

Realiza los cambios del proyecto C# dentro de este repositorio, en `src/CapaDatos/`, para que queden incluidos en los commits y pushes de `main`.
