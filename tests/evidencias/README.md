# Evidencias de pruebas

Esta carpeta conserva los logs de ejecución. El plan y los casos están en [`docs/PLAN_PRUEBAS.md`](../../docs/PLAN_PRUEBAS.md); el registro de incidencias está en [`docs/INCIDENCIAS_PRUEBAS.md`](../../docs/INCIDENCIAS_PRUEBAS.md).

Los archivos `evidencia-*.png` son imágenes legibles de los logs reales que acompañan esta entrega; el texto completo de cada log permanece en esta carpeta. La prueba de interfaz ya no toma capturas de las pantallas del programa.

- [Compilación](evidencia-compilacion.png)
- [Pruebas unitarias](evidencia-unitarias.png)
- [Integración SQL](evidencia-integracion.png)
- [Interfaz](evidencia-interfaz.png)

No se incluyen resultados inventados: cada log debe provenir de una ejecución real y mostrar `Total correcto: N`. Para integración, verificar también que se usó la instancia exclusiva `(localdb)\Entregable3Pruebas`.
